# Mami Berlian Agency Web App

Aplikasi web operasional untuk Mami Berlian Agency, mencakup:
- Manajemen lead dari media sosial
- Data pekerja & training
- Matching, penempatan, kontrak
- Invoice, pembayaran, dan talangan travel
- Task operasional (antar kerja, training, trip)

## Tech Stack
- Backend: PHP 8.x (cPanel compatible)
- Database: MySQL / MariaDB
- Frontend: Web (responsive)
- Hosting: Shared Hosting (cPanel)

## Roles
- Owner
- Admin Operasional
- Admin Media Sosial
- Trainer
- Driver
